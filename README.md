# YAFES ALEMİN MAKİNA — GitHub Pages

Statik, GitHub Pages uyumlu başlangıç web sitesi.

## Dosyalar
- `index.html` — Ana sayfa
- `makineler.html` — Makine kataloğu
- `yafes-alemin.html` — Kurucu / kurumsal profil
- `iletisim.html` — İletişim ve teklif
- `assets/style.css` — Tasarım
- `assets/app.js` — Basit istemci kodu
- `robots.txt` / `sitemap.xml` — SEO
- `.nojekyll` — GitHub Pages uyumluluğu

## GitHub Pages
Repository > Settings > Pages > Build and deployment > Source: Deploy from a branch > Branch: main > /(root) > Save.

Not: Özel alan adı bağlanmadan önce sitemap/canonical URL'leri mevcut GitHub Pages alanına göre değiştirmek gerekebilir.
